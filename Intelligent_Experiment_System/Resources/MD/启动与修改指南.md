## 二、怎样启动前端界面

### 2.1 前置条件

确保你的电脑已安装：

| 工具 | 版本要求 | 验证命令 |
|------|---------|---------|
| Node.js | ≥ 18.x | `node -v` |
| npm | ≥ 9.x | `npm -v` |
| Java JDK | 21 | `java -version` |
| Maven | ≥ 3.8 | `mvn -v` |

### 2.2 第一步：启动后端（必须先启动）

```bash
cd /Users/xikai/Documents/实训/Intelligent_Experiment_System/Backend/smart-lab-backend
mvn spring-boot:run
```

看到 `Started SmartLabBackendApplication` 即启动成功（端口 8080）。

### 2.3 第二步：启动前端（只需一个）

```bash
cd /Users/xikai/Documents/实训/Intelligent_Experiment_System/Main_File/Main_UI

npm install   # 仅首次
npm run dev
```

启动成功后终端会显示：
```
  ➜  Local:   http://localhost:5173/
```

浏览器打开 **http://localhost:5173/** 即可。

> **只需要启动一个前端！** Main_UI 内置了 `LoginView.vue`——未登录时自动显示登录表单，登录成功后自动切换到主界面。无需额外启动 Login_And_Register_UI。

### 2.4 登录流程（单应用内完成）

```
打开 http://localhost:5173
        │
        │  首次访问（无 token）
        ↓
   自动显示 LoginView 登录表单
        │
        │  输入 admin001 / Test123456
        ↓
   调用 POST /api/auth/login（端口 8080）
        │
        │  成功 → 保存 token → 页面自动刷新
        ↓
   检测到 token → GET /api/profile/me
        │
        ↓
   根据 userType 显示对应首页：
     1=学生 → 学生仪表盘
     2=教师 → 教师仪表盘
     3=管理员 → 管理员仪表盘
```

> 💡 如果后端尚未启动，可以点击登录页底部的「或使用离线 Demo 模式」跳过鉴权，直接以模拟数据进入。

### 2.5 独立登录页（可选）

`Login_And_Register_UI` 是一个独立部署的精美登录页（端口 5175），登录成功后会跳转到主界面。仅在需要单独部署登录页时使用：

```bash
cd /Users/xikai/Documents/实训/Intelligent_Experiment_System/Main_File/Login_And_Register_UI
npm install   # 仅首次
npm run dev
# 打开 http://localhost:5175
```

### 2.6 启动顺序总结

```
1. 启动后端      → mvn spring-boot:run（端口 8080）
2. 启动前端      → npm run dev（端口 5173，Main_UI）
3. 浏览器打开    → http://localhost:5173
```

> 只需启动一个后端 + 一个前端。未登录时 Main_UI 自动显示内置登录页。

#### 如果要新增一个功能模块，怎么做？

以「耗材与药剂管理」为例：

1. 在 `modules/` 下新建目录 `consumable/`
2. 创建 `model/` 放实体类，参考 `auth_profile/model/` 里的写法
3. 创建 `dao/` 放 Mapper 接口，继承 MyBatis-Plus 的 `BaseMapper<T>`
4. 创建 `service/` 放业务逻辑
5. 创建 `controller/` 放 REST 接口，使用 `@RestController` + `@RequestMapping`
6. 统一返回格式使用 `common/result/R.java`

#### 前端文件修改要点

| 你要改什么 | 改哪个文件 | 怎么改 |
|-----------|-----------|--------|
| 修改后端接口地址 | `vite.config.ts` | 改 `proxy` 里的 `target` |
| 添加新页面 | 新建 `.vue` 文件到 `components/` 下 | 在 `App.vue` 里加 `v-else-if` 路由 |
| 修改 API 请求 | `src/utils/` 下的请求封装 | 修改 axios 实例的 baseURL |
| 修改页面布局 | 对应的 `.vue` 文件 | `<template>` 是 HTML，`<script>` 是逻辑，`<style>` 是样式 |
| 添加导航菜单项 | `HeaderBar.vue` | 在菜单数组里加一项 |

## 四、前后端通信方式

```
浏览器 (Vue 3)                 后端 (Spring Boot)
     │                              │
     │  GET /api/v1/auth/login      │
     │ ──────────────────────────>  │
     │                              │
     │  { code: 200, data: {...} }  │
     │ <──────────────────────────  │
     │                              │
     │  GET /api/v1/labs            │
     │ ──────────────────────────>  │
     │                              │
     │  { code: 200, data: [...] }  │
     │ <──────────────────────────  │
```

- 前端 Axios 请求 `/api/xxx` → Vite 代理转发到 `http://localhost:8080/api/xxx`
- 后端统一返回格式：`{ code: 200, message: "success", data: ... }`
- 代理配置在 `Main_UI/vite.config.ts` 第 10 行

## 五、常见问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 前端页面空白 | 后端没启动 | 先执行 `mvn spring-boot:run` |
| API 请求报 404 | 接口路径不对 | 检查后端 Controller 的 `@RequestMapping` |
| 跨域错误 | Vite 代理没配好 | 确认 `vite.config.ts` 中 proxy 配置正确 |
| Unity WebGL 加载失败 | 不是通过 HTTP 服务器打开的 | 用 `python3 -m http.server` 或 Live Server 打开 |
| `npm install` 失败 | 网络问题或 Node 版本太低 | 切换 npm 镜像源：`npm config set registry https://registry.npmmirror.com` |
| 后端启动报数据库连接错 | MySQL/Redis 没启动或配置不对 | 检查 `application-dev.yaml` 中的数据库连接信息 |
