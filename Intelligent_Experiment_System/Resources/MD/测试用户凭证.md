## 三、登录方式

### 方式一：主界面内嵌登录（推荐，只需启动一个前端）

```bash
# 终端 1：启动后端
cd Intelligent_Experiment_System/Backend/smart-lab-backend
mvn spring-boot:run

# 终端 2：启动前端
cd Intelligent_Experiment_System/Main_File/Main_UI
npm install   # 仅首次
npm run dev
```

浏览器打开 `http://localhost:5173`。未登录时自动显示登录表单，输入用户名密码即可登录。登录成功后自动切换到对应角色的首页。

### 方式二：独立登录页（可选，更精美的 UI）

```bash
cd Intelligent_Experiment_System/Main_File/Login_And_Register_UI
npm install   # 仅首次
npm run dev
```

打开 `http://localhost:5175`，登录成功后自动跳转到主界面。

### 方式三：离线 Demo 模式（不需要后端）

在主界面登录页点击「或使用离线 Demo 模式」，系统会默认以管理员角色进入（数据均为 Mock）。

## 四、数据生成机制

测试用户由后端 `TestDataInitializer` 组件在首次启动时自动创建：

- 位置：`Backend/.../auth_profile/config/TestDataInitializer.java`
- 时机：Spring Boot 启动时执行 `@PostConstruct`
- 幂等：已存在的用户不会重复创建
- 数据链：`person` → `user_account` → `user_profile` 三表联动

如需重置测试数据，连接数据库执行：

```sql
DELETE FROM user_profile WHERE user_id IN (SELECT id FROM user_account WHERE username IN ('student001','teacher001','admin001'));
DELETE FROM user_account WHERE username IN ('student001','teacher001','admin001');
DELETE FROM person WHERE person_name IN ('张同学','李老师','王管理员');
```

然后重启后端即可重新生成。
