## 🔧 Unity 场景搭建步骤

### 步骤 1：创建 LabDataProvider

在场景中创建一个空 GameObject，命名为 `LabDataProvider`，挂载 `LabData.cs` 脚本。

在 Inspector 中设置：
- `Current Scene Lab Type`: `教学实验室`（Class_Lab 场景）
- `Mock Lab Data`: 留空（脚本会自动生成）

### 步骤 2：设置大屏触发器

1. 选中场景中的大屏模型（大屏幕 GameObject）
2. 添加 `Box Collider` 组件：
   - 勾选 **Is Trigger** ✓
   - 调整 Size 使其略大于大屏，向前延伸 3-4 个单位（覆盖玩家靠近范围）
3. 挂载 `ScreenTrigger.cs` 脚本

### 步骤 3：创建提示 UI（World Space）

在大屏前方创建一个 World Space Canvas：

```
Hierarchy:
  BigScreen (大屏模型)
  └── PromptCanvas (Canvas)
       ├── PromptPanel (Image - 半透明深色背景)
       │   └── PromptText (TextMeshPro - "按 Space 查看大屏信息")
```

- Canvas Render Mode: **World Space**
- Canvas 位置放在大屏前方约 1m 处
- Canvas 缩放约 (0.01, 0.01, 0.01)
- 将 `PromptUI` (Canvas GameObject) 拖入 ScreenTrigger 的 `Prompt UI` 字段
- 将 `PromptText` (TextMeshProUGUI) 拖入 `Prompt Text` 字段

### 步骤 4：创建主信息面板 UI（Screen Space Overlay）

这是核心 UI，建议使用 Screen Space Overlay 以获得最佳交互体验。

```
  │   ├── HeaderBar
  │   │   ├── TitleText (TMP)
  │   │   └── CloseButton (Button)
  │   ├── TabBar
  │   │   ├── TabOverviewButton (Button)
  │   │   ├── TabBorrowButton (Button)
  │   │   ├── TabOverviewHighlight (Image - 蓝色高亮条)
  │   │   └── TabBorrowHighlight (Image)
```

### 步骤 5：绑定引用

在 `LabInfoPanel` 的 Inspector 中，将所有 UI 元素拖入对应字段：

| 脚本字段 | 绑定对象 |
|----------|----------|
| `titleText` | HeaderBar/TitleText |
| `closeButton` | HeaderBar/CloseButton |
| `tabOverviewButton` | TabBar/TabOverviewButton |
| `tabBorrowButton` | TabBar/TabBorrowButton |
| `overviewPanel` | MainContainer/OverviewPanel |
| `cardContainer` | OverviewPanel/ScrollView/Viewport/CardContainer |
| `cardPrefab` | LabCard 预制体 |
| `borrowPanel` | MainContainer/BorrowPanel |
| `borrowFormController` | BorrowPanel (挂载 LabBorrowFormUI.cs) |

### 步骤 6：连接触发器与面板

将 `LabInfoPanel` GameObject 拖入 `ScreenTrigger` 的 `Lab Info Panel` 字段。

## 🎨 UI 样式参考

### 配色方案

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色调 | 科技蓝 | `#4A90D9` |
| 成功/开放 | 绿色 | `#27AE60` |
| 警告/维护 | 橙色 | `#F39C12` |
| 错误/关闭 | 红色 | `#E74C3C` |
| 背景遮罩 | 半透明黑 | `rgba(0,0,0,0.5)` |
| 卡片背景 | 白色 | `rgba(255,255,255,0.95)` |
| 面板背景 | 毛玻璃白 | `rgba(255,255,255,0.85)` |

### 卡片布局建议

- 使用 `GridLayoutGroup` 实现自适应网格
- Cell Size: 380 × 180
- Spacing: (16, 16)
- Padding: (20, 20, 20, 20)
- 3 列布局（适合 1200px 宽面板）

## 🔄 数据流程

```mermaid
sequenceDiagram
    participant P as 玩家
    participant T as ScreenTrigger
    participant D as LabDataProvider
    participant UI as LabInfoPanelUI
    participant F as LabBorrowFormUI

    P->>T: 走近大屏 (进入 Trigger)
    T->>P: 显示 "按 Space 查看大屏信息"
    P->>T: 按下 Space
    T->>UI: 打开面板 + 锁定光标
    UI->>D: 请求实验室数据
    D-->>UI: 返回 List&lt;LabInfoData&gt;
    UI->>UI: 生成卡片 / 刷新表单下拉

    Note over UI: Tab 0 - 浏览实验室卡片

    P->>UI: 点击 "借用申请" Tab
    UI->>UI: SwitchTab(1)
    P->>F: 填写表单 → 点击提交
    F->>D: SubmitBorrowRequest()
    D-->>F: 返回成功/失败
    F->>P: 显示提交结果

    P->>T: 离开范围 / 按 Space
    T->>UI: 关闭面板 + 解锁光标
```

```csharp
    string url = $"http://localhost:8080/api/labs?type={labType}";
    using var www = UnityWebRequest.Get(url);
    await www.SendWebRequest();
    // JSON 解析...
}
```

### 2. 扩展到其他场景

在 `Common_Lab`、`Computer_Lab` 等场景中复用大屏系统：
- 修改 `LabDataProvider.currentSceneLabType` 为对应类型
- 数据自动过滤为该类型的实验室

如果 Unity 发布为 WebGL 并嵌入 Web 平台：
```csharp

[DllImport("__Internal")]
private static extern void SubmitReservation(string json);
```
